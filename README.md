# 🧁 Baker's Nest

A full-stack online bakery platform built using the **MERN stack**, designed to provide a smooth experience for customers as well as bakery administrators.

The application includes a responsive landing page, product browsing, authentication, shopping cart, checkout, online payments, and an admin panel for managing products and orders.

🔗 **Frontend:** https://bakers-nest-1.onrender.com

🔗 **GitHub Repository:** https://github.com/itsNitika/Bakers-nest

## ✨ Features

### 1. Customer Features

- Responsive bakery landing page
- Browse bakery products
- Product details and categories
- Add products to shopping cart
- Update cart quantities
- Remove products from cart
- Smooth checkout experience
- Secure login and signup using Auth0
- Online payment integration using Razorpay
- Responsive UI for different screen sizes

### 2. Authentication

- Integrated **Auth0** for secure authentication
- Login and signup functionality
- Protected user access
- Secure authentication flow

### 3. Shopping Cart

- Add products to cart
- Increase or decrease product quantity
- Remove products from cart
- Global cart state management using **React Redux**
- Cart data handled efficiently across the application

### 4. Payment

- Integrated **Razorpay** for online payments
- Secure payment authentication
- Supports multiple payment methods provided through Razorpay

### 5. Admin Panel

The admin panel allows the bakery owner/admin to manage the application efficiently.

- Add new products
- Edit existing products
- Manage products
- View and manage orders
- Improve the overall order-processing workflow

### 6. Backend

- RESTful APIs using Express.js
- MongoDB database integration
- Mongoose for database modeling
- Backend APIs for application data and operations
- Structured server-side architecture
